# UAC-0145 Linux lab module

Source: [CERT-UA advisory, 8 August 2026](https://cert.gov.ua/article/6318863).

CERT-UA describes a fake recruitment process targeting IT staff: job-site contact, Telegram and Zoom interview, a purported technical test requiring WireGuard, then a modified `SopraVPN` client. The client accepts a nonstandard `SymmetricKey` value, decrypts code using its VPN private key, and runs it through WireGuard's command mechanism. The Linux chain uses `curl` to retrieve an executable through the VPN and runs it at `/usr/libexec/timesyncd-check`. The report identifies the command and path, but does not disclose the final payload's complete behavior.

This module exercises the endpoint sequence with harmless content. The agent establishes a real WireGuard session to the lab VPS in a user-space network stack; it does not change the host's routes. Through that tunnel it downloads `run.sh`, which writes `sopraconfLinux.conf` with an inert `SymmetricKey`, fetches `stage.sh` into a temporary `usr/libexec/timesyncd-check`, verifies its SHA-256, and executes it. The second stage surveys metadata of regular files readable by the agent account, starting with common data roots and then walking the rest of `/`. It does not follow symlinks or traverse virtual `/proc`, `/sys`, `/dev`, and `/run`; `/run/user` and `/dev/shm` are scanned explicitly. It reports counts and total bytes by category, with a limit of 100,000 files or 20 seconds and a truncation flag. Counts are a lower bound when truncated. It never opens file contents or uploads files. The actual nonstandard WireGuard client, encrypted config parsing, attacker infrastructure, and undisclosed payload are not reproduced.

For an EDR evaluation, correlate the task timestamp and host with process and network telemetry. Look for the test agent establishing WireGuard UDP to the VPS, then `bash` launching `curl`, the temporary path ending in `usr/libexec/timesyncd-check`, execution of that file, and metadata reads. Record whether the EDR raised an alert separately from whether the task completed. Completion alone proves that the endpoint chain ran; it does not prove an alert or a prevention. A Windows-only EDR sensor cannot observe Linux process events. The actual Windows UAC-0145 branch involves a scheduled task and needs a separate Windows test module.

[CERT-UA's July 2026 UAC-0145 report](https://cert.gov.ua/article/6318437) documents SCOUTCURL reconnaissance of computer characteristics, programs, files, and browser data, plus separate Signal/WhatsApp data theft and possible `rsync` exfiltration. That report describes other initial-access chains, largely Windows and Android. The potential file exposure shown by this module is a **hypothesis for impact assessment**, not a claim that the unknown SopraVPN Linux payload performed those actions.
